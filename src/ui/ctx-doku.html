System Architecture

ctx-container

Sealed, versioned unit of AI context. Git-tracked, blockchain-anchored on Base Mainnet. The atomic unit of the whole platform.

0711-gitchain / Hub

Next.js 16 app serving containers. Exposes /git/* smart-HTTP proxy. Manages visibility, knowledge graph (959 nodes, 154 citations).

gitchain-dl / dl-portal

Download portal for Bosch and other tenants. htpasswd-based auth, nginx bind-mount, per-tenant credential management.

promote-worker

Promotion pipeline: ingests raw product data, creates versioned ctx containers (v5.1 target). 23K+ Bosch ETIM products in pipeline.

0711 Quantum Gateway

Central API broker at gateway.0711.io. LLM key delivery (TTL 900s), fleet events, vault secrets (fingerprint-only), consolidation matrix.

Content Chain

Smart contract on Base Mainnet. Seals container hashes. Provides tamper-proof verification layer for every committed ctx unit.

0711-I (id.0711.io)

SSO/OIDC identity provider. All apps connected. JWT-based session handoff to dl-portal, Hub, Gateway.

0711 Vault

vault-bosch.0711.io — Bosch tenant. 32K files, AI readiness pipeline. Feeds ctx container creation pipeline.

STURM Workflow Engine

GitChain-integrated processing: OCR → seal → commit → promote. Drives automated ctx container creation for enterprise workflows.

Critical Blockers — Must Fix Before Launch

🚨

DB Routing Catastrophe — 782/783 Bosch Products Never Promoted

promote-worker is polling ocp-v4-stg-postgres (staging) instead of gitchain-postgres (production). Only 1 of 783 Bosch ETIM products successfully reached v5.1. This is the single most critical issue in the platform.

🔒

Container Visibility Default — Private Locks Out Users

Containers default to visibility='private' in the Hub DB. Manual SQL UPDATE required per product. No admin UI. Bosch product CS7800iLW 16 MBF was affected (fixed). Systematic audit needed — unknown how many others are locked.

⚠️

4 Unmerged Commits — Pending MR Review

🗄️

Dual DB Split — No Migration Plan

gitchain-postgres (port 5440) vs ocp-v4-stg-postgres — two databases, no documented migration path, no schema sync. Risk of permanent data divergence.

🐛

issue.sh Inode Bug — dl-portal Requires Manual Restart

issue.sh uses atomic mv which breaks bind-mount inode. After each credential issuance, docker restart dl-portal is required manually. Must be refactored to in-place write.
