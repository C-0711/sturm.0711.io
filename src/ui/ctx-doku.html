Was wird gebaut

CTX-Bootstrap macht aus dem ersten Context-Window einer beliebigen LLM-Session (ChatGPT, Claude, Gemini, Cursor, …) einen quantum-indexed retrieval container, der von anderen LLMs/Agenten per plain HTTP angesprochen werden kann. Same wire format, no SDK.

    📄 services/gateway-api/src/sturm-ctx-broker.ts (neu)
    curl -H "Authorization: Bearer $BOOTSTRAP" /api/tokens/sturm-ctx liefert { token, expires_at, ttl_seconds }.

  4. nginx limit_req_zone für /ctx/* B4 @Operator
    ~/0711/0711-STURM/nginx/sturm.0711.io.conf erweitern:

limit_req_zone $binary_remote_addr zone=ctx_bootstrap:1m  rate=5r/h;
