2) Integration objective

Ship one coherent design system and interaction language across STURM, Gateway, and related sister surfaces without breaking live operational workflows. Deliver in phases with measurable acceptance gates, not a big-bang replacement.

  • Preserve all existing backend contracts and production flows first.
  • Migrate UI shell + components incrementally behind feature flags.
  • Track parity with screenshot diffs, route-level smoke, and API contract checks.
